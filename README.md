# Blog — Computação Visual (2026.2)

Blog da disciplina de Computação Visual, feito com **Jekyll** e publicado no
**GitHub Pages** (tema `minima`, skin escuro).

## Como criar um novo post

Crie um arquivo dentro de `_posts/` com o nome no formato
`AAAA-MM-DD-titulo.md` e comece com o cabeçalho:

    ---
    layout: post
    title: "Título do post"
    date: 2026-09-01
    categories: [aulas]
    tags: [tag1, tag2]
    ---

    Conteúdo do post em Markdown...

O post aparece automaticamente na página inicial.
